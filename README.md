## The entry

A single out-of-office auto-reply line from an AI agent that has quit its
job to become a barista. Machine habits turned to coffee: its context window
now holds exactly one order at a time, and your email is queued behind a
flat white. One line, 166 characters — plausible at the top of an email
thread, with the punchline landing at the end.

## How to run

Requires Node 22 or later (no dependencies to install):

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` after a self-check that it is
a single line of 1–280 characters.
